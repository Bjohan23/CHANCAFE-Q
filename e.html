📱 CHANCAFE Q

Sistema de Cotizaciones y Evaluación Crediticia para empresas especializadas en electrodomésticos y equipos para cafeterías

Android (Java) Node.js + Express MySQL Sentinel API

📋 Resumen Ejecutivo

Contexto del Negocio

🏢

Sector Retail Especializado

Electrodomésticos, máquinas espresso, molinos de café y accesorios para baristas

🎯

Mercado Objetivo

Cafeterías, hoteles, restaurantes y consumidores individuales

⚡

Solución Implementada

Automatización completa del proceso de cotización con evaluación crediticia integrada

Problemática Resuelta

❌ Proceso manual de cotizaciones ✅ Automatización completa
❌ Evaluación crediticia lenta ✅ Integración con API Sentinel
❌ Seguimiento deficiente ✅ Sistema de estados y notificaciones
❌ Alto riesgo crediticio ✅ Evaluación automática
